# Projetos-com-QT-Cpp

# 🎓 Qt Creator com C++: Jornada de Aprendizagem

Este repositório serve como um diário de bordo e coleção de projetos para documentar a minha evolução no desenvolvimento de aplicações desktop utilizando **C++** e o ecossistema do **Qt Creator**.

O objetivo é registar cada etapa de aprendizado, desde conceitos básicos de interfaces gráficas (GUI) até lógicas mais complexas e estruturadas.

---

## 🚀 Tecnologias Utilizadas

*   **Linguagem:** C++ (Padrão C++17 ou superior)
*   **Framework:** Qt Framework (Widgets / QML)
*   **IDE:** Qt Creator
*   **Compilador:** GCC / Clang (Linux) ou MinGW (Windows)

---

## 📂 Estrutura do Repositório

O projeto está dividido em pastas cronológicas para facilitar o acompanhamento da evolução do código:

```text
qt-learning-journey/
├── 01_OlaMundo/           # Primeiros passos e configuração do ambiente
├── 02_Layouts_E_Widgets/  # Uso de Botões, Inputs, Labels e alinhamentos
├── 03_Signals_E_Slots/    # Entendendo o sistema de eventos e cliques do Qt

└── README.md
```

---

## 🛠️ Como Executar os Projetos

Para rodar qualquer um dos subprojetos no seu computador:

1. Instale o **Qt Creator** e o **Qt Framework** através do instalador oficial da Meta/Qt.
2. Clone este repositório no seu terminal:
   ```bash
   git clone https://github.com
   ```
3. Abra o Qt Creator.
4. Vá em **File > Open File or Project** e selecione o ficheiro `.pro` (ou `CMakeLists.txt`) da pasta que deseja estudar.
5. Clique no botão **Run** (ícone do triângulo verde no canto inferior esquerdo) para compilar e iniciar a aplicação.
